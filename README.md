# FixtureLang 0.1.0: runnable playground

Requires Node.js 20 or newer. No dependency installation is needed.

Run `npm start`, then open the loopback URL printed by the server. Keep it running while using the playground. All fixture generation and downloads stay local.

This bundle contains the built playground, language reference, examples, license, and credits. The separate fixturelang-0.1.0.zip archive includes the full source, CLI, tests, and build tooling.

CSV export requires an explicit raw or spreadsheet-mode choice. Raw fixture strings are intentionally preserved; spreadsheet mode changes formula-like strings. JSON preserves missing properties and explicit nulls.
